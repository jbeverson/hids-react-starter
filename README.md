# React starter for the patient app assignment

An empty React + Vite project with GitHub Copilot instructions and a place for your use case card and reflection.

## Steps
1. Click **Use this template**, then **Create a new repository** (private is fine).
2. In your new repository, click **Code**, then the **Codespaces** tab, then **Create codespace on main**. The first start takes a few minutes while packages install.
3. In the terminal at the bottom, run:

       npm run dev

   The terminal will then look stuck, with a line saying VITE is ready. That means it is working. Leave it alone, and open a second terminal with the **+** button if you need to run anything else.
4. Open the app in your browser: click **Open in Browser** on the pop-up, or open the **Ports** tab and click the globe icon on the row for port 5173. If the Ports tab is empty, press Ctrl+Shift+P (Cmd+Shift+P on a Mac), run **Ports: Forward a Port**, and enter 5173. You should see "Patient app starter."
5. Open **Copilot Chat** (the chat icon) and choose the mode that edits files and asks before running commands. In the current version that is **Interactive**. Avoid **Autopilot**.
6. Follow the class handout. Use only fake data, and read what Copilot asks permission to do before you accept it.
7. When you finish, fill in `PROMPT_LOG.md` (your use case card and reflection), then commit and push your changes (Source Control panel) and stop the codespace.
