# React starter for the patient app assignment

An empty React + Vite project with GitHub Copilot instructions and a prompt log.

## Student steps
1. Click **Use this template**, then **Create a new repository** (private is fine).
2. In your new repository, click **Code**, then the **Codespaces** tab, then **Create codespace on main**. The first start takes a few minutes while packages install.
3. In the terminal at the bottom, run:

       npm run dev

4. When the pop-up says the app is available, click **Open in Browser** (or open the **Ports** tab and click the link for port 5173). You should see "Patient app starter". That is rung 1.
5. Open **Copilot Chat** (the chat icon), switch the mode to **Agent**, and describe what you want to build.
6. Keep `PROMPT_LOG.md` up to date as you go.
7. Before you leave: commit and push your changes (Source Control panel), then stop the codespace.

## If something fails
Write down what happened in `PROMPT_LOG.md` (the exact error text and a screenshot) and keep going with the next part of the assignment. A documented failure earns full credit.

## Files
- `src/App.jsx`: the page
- `.github/copilot-instructions.md`: the rules Copilot follows in this project
- `PROMPT_LOG.md`: your record of prompts and results
